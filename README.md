# Блог-платформа (Кейс-задача № 3)

Технологическая (проектно-технологическая) практика.ИСиТ_ВР(6)(1/3)_2509 Кейс-задача №3

## Основной функционал

- Регистрация и вход пользователей (без хеширования паролей)
- Создание постов с заголовком, текстом, тегами и выбором публичности
- Приватные посты (видны только автору)
- Лента постов на основе подписок (публичные посты авторов, на которых подписан)
- Просмотр всех публичных постов
- Поиск по тегам
- Редактирование и удаление своих постов
- Возможность подписываться / отписываться от других пользователей
- Комментирование постов

## Технологии

- Node.js + Express 
- Хранение данных в JSON-файлах (папка `data/`)
- HTML, CSS, JavaScript 

## Установка и запуск

1. Установите [Node.js](https://nodejs.org/) (версия 14 или выше).
2. Склонируйте репозиторий:
   ```bash
   git clone https://github.com/ваш_username/blog-app.git
3. Перейдите в папку проекта: cd название_репозитория
4. Установите зависимости: npm install
5. Запустите сервер: node server.js
6. Откройте браузер по адресу: http://localhost:3000
